各授業回の学習事項

第1回 WWW と HTML

HTML文書の基本的な書き方について学んだ。そして、基本的な書き方を軸に、見出しをつけたり、ハイパーリンクをつけたり、画像を埋め込む方法などについて学んだ。 また、やり方がわからなくてもWebなどで調べ、そしてMDNで確認して使うことで自身のやりたいことを実行していけるということを学んだ。

演習の成果:演習1-4:HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

CSSを使ってWebページを装飾する方法について学んだ。HTMLだけのWebページでは文字の大小程度のデザインしかなかったが、CSSを使うことで色や配置などを自由にデザインすることができるようになった。また、開発ツールを使うことでWebサイト上でデバックを行ったり、デザインの確認などを行うことができることを学んだ。

演習の成果:演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

JavaScriptをWebページに追加する方法を学んだ。また、JavaScriptの基本的な構文と、プログラムが正しく実行されているかデバックする方法について学んだ。デバックの方法として、例外で停止を行うことによってエラーが発生した地点で一時停止して内容を確認する方法と、ブレークポイントを設定して変数の内容を確認する方法を学んだ。

演習の成果:演習3-6: オブジェクトの参照
