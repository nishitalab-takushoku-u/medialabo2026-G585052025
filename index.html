「Webコンテンツ作成」の成果

本テーマについて

本テーマではHTML等を用いてWebページを作成する。またCSSでのレイアウトの指定、JavaScriptでのWebページを動的に変更することやイベント駆動プログラミング、外部サーバーとの通信処理ができるようになることが学習目的である。

プロジェクト課題について

グルメ情報のジャンルを指定して検索できるWebサイトを作成した。ジャンルは17の選択肢の中からプルダウンメニューで好きなように選択することができる。検索すると店名や画像など、店の詳細情報が一覧になって表示される。店の詳細情報は見やすいように並べ替え、一目で重要な情報を確認することができるようになっている。また、プルダウンメニューの下に検索結果の件数が表示され、一目で何件の情報があるか確認することができる。できるだけすぐに情報を確認しやすいようにすることで、情報を探したりする必要がないような表示形式になるように工夫した。

プロジェクト課題で作成したページ:project.html

数当てゲーム

コンピューターが決めた1〜10の乱数の値をユーザーが予想する。ユーザーは予想した数を最大3回まで入力することができる。ページにはテキストボックスとボタンが設置されており、ユーザーはテキストボックスに予想する数を入力し、ボタンを押すと入力した数が当たっているか外れているかの結果が表示される。ユーザーが入力した数が外れていた場合、ヒントとして答えの数が入力よりも大きいか小さいかを表示する。3回以内に答えの数を当てることができればユーザーの勝ち、当てることができなければ負けである。外した回数が3回に達するか答えの数を当てることができればゲームが終了し、答えの数が表示される。

数当てゲームのページ:kazuate.html

各授業回の学習事項

第1回 WWW と HTML

HTML文書の基本的な書き方について学んだ。そして、基本的な書き方を軸に、見出しをつけたり、ハイパーリンクをつけたり、画像を埋め込む方法などについて学んだ。 また、やり方がわからなくてもWebなどで調べ、そしてMDNで確認して使うことで自身のやりたいことを実行していけるということを学んだ。

演習の成果:演習1-4:HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

CSSを使ってWebページを装飾する方法について学んだ。HTMLだけのWebページでは文字の大小程度のデザインしかなかったが、CSSを使うことで色や配置などを自由にデザインすることができるようになった。また、開発ツールを使うことでWebサイト上でデバックを行ったり、デザインの確認などを行うことができることを学んだ。

演習の成果:演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

JavaScriptをWebページに追加する方法を学んだ。また、JavaScriptの基本的な構文と、プログラムが正しく実行されているかデバックする方法について学んだ。デバックの方法として、例外で停止を行うことによってエラーが発生した地点で一時停止して内容を確認する方法と、ブレークポイントを設定して変数の内容を確認する方法を学んだ。

演習の成果:演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

フォーム要素とイベント処理、DOMについて学んだ。フォーム要素はテキストボックスやボタンなどであり、ユーザーからの入力を受けることができ、イベント処理はそのボタンが押された時に処理を実行することができる。また、DOMはフォーム要素の入力値の取得や、HTMLの検索やテキストの変更ができることを学んだ。

演習の成果:演習4-10: 足し算ページ

第5回 イベント処理

DOMを使って、要素を新規作成したり編集したり、削除したりする方法を学んだ。また、新規作成した要素を検索した要素のそばに配置することができ、この配置は要素の内部と直後のどちらにも配置することができる。要素の新規作成は個別で行うだけでなく、例えば新しいリストの中身をまとめて作成することもできる。ほかに要素を削除する際も、個別に削除するだけでなくリストを丸ごと削除することもできる。

演習の成果:演習5-7: DOMプログラミング(2)

第6回 Ajax通信

axiosを使ってAjax通信を行い、サーバーからデータを取得する方法について学んだ。データ取得までの流れとしては、まずサーバーにリクエストを送信し、その後サーバーからレスポンスを受け取る。この通信は失敗することもあるため、エラー処理も記述する。また、Ajax通信は非同期通信であるため、リクエストを送信してからレスポンスを受け取るまでの待ち時間に他の処理を行うことができる。

工夫点，苦心点，強調点，感想

Webページの制作においての工夫点は、閲覧者が見やすいWebページを作ることである。なぜなら私が普段Webページを閲覧している時、そのWebページを使いにくいと感じる瞬間は、知りたい情報がどこにあるかを見つけにくい時だからである。私は情報の見つけやすさはWebページの見やすさに起因すると考えている、そのためCSSでのレイアウトや情報を表示する順番や場所などに気を使い、できる限り知りたい情報が一目で把握できるように工夫した。また、index.htmlもプロジェクト課題のページもどちらも比較的シンプルなレイアウトにし、情報が探しやすく、雑然として見えにくいということがないようにした。ほかにindex.htmlには少しだけ白黒以外の色を使用しているが、これも題名などの注目してほしい部分にのみ使用し、文中には使用しないことによりページ全体を見た時にどこを最初に見ればいいかがわかりやすいように工夫した。これらの工夫から、見やすく、情報の探しやすいWebページを作ることができたのではないかと思う。

苦心点は、ページの見た目を自分の思い通りのレイアウトにすることである。中でも特にCSSでの余白の設定に苦心した。思い通りの位置に余白ができず、文字や画像の位置がずれることがよくあった。そのため余白の場所を変えて何度も試行錯誤することにより、思い通りの位置に余白を設定することができた。他にエラーの修正に苦心した。初めはなぜエラーが起こっているのかわからなかったが、エラーの内容を読んだり例外で停止するなどしてエラーになっているプログラムをウェブ開発ツールで確認したりすることで、エラーを修正できるようになった。

強調点はWebページの見やすさである。シンプルな見た目と情報をまとめて配置することにより、余計に迷ったりすることなく見たい情報を見つけられるようにした。

Webコンテンツ作成の授業を通して、Webページがどのように構成されているかの仕組みを知り、それを自身で制作することができるようになった。普段検索して見ているWebページの中で、一見シンプルに見えるページも多くの要素で構成されており、利用者が使いやすいように工夫されていることを感じた。また、今回の授業では学習しなかったが、スマホでWebページを見ていた時に、PCでページを見た時とレイアウトの違うサイトが多くあった。スマホとPCでは画面のサイズやアスペクト比が異なるため、スマホ専用にレイアウトがされているととても見やすいと感じた。今後Webページについて学ぶ機会があればこういった点にも注目して学習していきたいと感じた。ほかに今回のプロジェクト課題で通信した時にウェブ開発ツールからデータを見ることで資料にはない情報も利用でき、Webページ作成の幅が広がった。今後機会があれば、今回学んだことを活かして他の要素も使ったWebサイトの作成をしてみたいと感じた。
